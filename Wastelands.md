# Wastelands · основа и три твинка

На всех четырёх сеансах используй одну версию TWD Farm. Для установки из папки запусти `Создать ярлык.bat` один раз для установки зависимостей. Для чтения английских названий кнопок твинку нужен компонент распознавания текста Windows (English OCR). Для RDP подходит 1366×768 с полноэкранным Roblox.

1. Открой обычный ярлык **TWD Farm** или `Запуск.bat`. В левом меню выбери **Wastelands → Основа**. Выбери локальный IPv4, доступный из RDP-сеансов, и нажми «Включить связь». Твинки подключаются к TCP-порту 47631. На одном хосте можно использовать 127.0.0.1. Протокол рассчитан на доверенную частную сеть, передаёт команды и запрошенные кадры по HTTP.
2. Для каждого твинка нажми «Скопировать код» в его строке. В его сеансе открой **TWD Farm → Wastelands → Твинк**, вставь код, проверь номера слотов и нажми «Подключиться». Сверни помощник, оставив Roblox активным и видимым в сеансе.
3. На основе укажи имя из карточки PARTY INVITE и сложность, нажми «Запустить помощника». Пригласи твинков на Wastelands. Каждый проверяет карту и имя, принимает приглашение и голосует при загрузке. Матч в игре запускаешь ты.
4. На основе вручную поставь свою пару в жёлтой зоне и нажми READY. Твинки ставят Plunger, нажимают READY, ставят TV, затем Amplifier и Screen. Только титаны получают улучшения, по одному уровню по очереди. Четыре игровых слота на твинке задаются явно, чтобы изменение цены не перепутало персонажей.
5. Каждая строка панели управляет своим твинком. Aerial Attack можно вызвать всем сразу. Teleport запрашивает кадр конкретного твинка. Кликни на землю на кадре, чтобы передать цель. При смене ракурса или занятой цели запрос отклоняется. Срабатывание Teleport подтверждается закрытием Unit Manager. Для остальных способностей панель различает отправку команды и нажатие, игровой эффект требует проверки в матче.

## Расстановка

Жёлтый угол размечен для четырёх пар Plunger/TV. Первая пара принадлежит основе. Зелёная полоса зарезервирована под трёх титанов основы. По умолчанию твинки 1, 2 и 3 получают соответственно верхнюю ближнюю, нижнюю ближнюю и дальнюю голубые полосы на твоём скриншоте. Каждая пара титанов имеет несколько пробных точек внутри своей полосы.

При подсветке дороги твинк ищет характерный излом Wastelands и переводит общие координаты в координаты своего окна. Координатор проверяет соседние резервы, включая ещё не подтверждённые постановки. Если результат клика неясен, место остаётся занятым. Открой «Места юнитов» на основе и подтверди или освободи его после проверки в игре. После пяти занятых точек потребуется освободить место и повторить попытку. Для нового матча нажми «Остановить помощника», затем «Запустить помощника».

F6 останавливает локального твинка. Общая кнопка «Остановить помощника» прекращает матч помощника для всех подключённых твинков. При потере сети твинк прекращает новые игровые действия и пробует восстановить связь. Оставляй панель основы открытой: состояние матча хранится на ней до нового матча или выхода из программы. При проверке присутствия в игре требуется ручной ответ.
