# TWD Farm

Бот-макрос для Roblox «Toilet Warfare Defense»: сам проходит карту Invaded City (HARD и NIGHTMARE), матч за матчем.

## Установка

1. Поставь Python 3.10+ с [python.org](https://www.python.org/downloads/) (отметь «Add python.exe to PATH»).
2. Скачай этот репозиторий (Code → Download ZIP) и распакуй в любую папку.
3. Запусти `Создать ярлык.bat` — он поставит библиотеки и сделает ярлык «TWD Farm» на рабочем столе.
4. Открой «TWD Farm», в настройках выбери режим и вставь ссылку своего приватного сервера.
5. Зайди в игру и нажми «Старт» (или F8). Остановить — F6.

## Обновления

Бот обновляется сам: при запуске и между матчами он сверяет свою версию с `version.json` в этом
репозитории, скачивает новый `twd_bot.py`, проверяет его и перезапускается (фарм продолжается).
Прошлая версия остаётся рядом как `twd_bot_prev.py`. Отключить можно в настройках («Обновляться автоматически»).

## Что не хранится в репозитории

`settings.json` (токен Discord-бота, ссылка приватного сервера), журнал и снимки из папки `debug` —
они остаются только на твоём компьютере.
