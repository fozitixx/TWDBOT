# TWD Farm

TWD Farm 6.0.6 для Roblox «Toilet Warfare Defense» объединяет фарм Invaded City и совместный режим Wastelands для основы и трёх твинков.

## Установка

1. Поставь Python 3.10+ с [python.org](https://www.python.org/downloads/) (отметь «Add python.exe to PATH»).
2. Скачай этот репозиторий (Code → Download ZIP) и распакуй в любую папку.
3. Запусти `Создать ярлык.bat` — он поставит библиотеки и сделает ярлык «TWD Farm» на рабочем столе.
4. Открой «TWD Farm». Для совместной игры нажми **Wastelands** в левом меню и выбери вкладку **Основа** или **Твинк**. [Настройка Wastelands](Wastelands.md)
5. Для фарма Invaded City укажи сложность и ссылку приватного сервера в настройках, затем нажми «Старт» на главной или F8. F6 останавливает активный режим.

## RDP в 1366×768

Открой подключение командой `mstsc /w:1366 /h:768` и укажи адрес удалённого ПК.
Для сохранённого профиля можно использовать `mstsc "твинк.rdp" /w:1366 /h:768`.
В удалённом сеансе разверни Roblox на весь экран (F11). Макрос считает координаты от игровой области.
Размер кадра можно проверить через `twd_bot.py diag`.

В поле «Разрешение экрана при старте фарма» значение `1366` означает `1366×768`.
В активном RDP размер задаёт клиент подключения. После выхода из RDP через tscon
макрос может выставить выбранный режим, если его поддерживает драйвер.

## Обновления

Бот обновляется сам: при запуске и между матчами он сверяет свою версию с `version.json` в этом
репозитории, скачивает новый `twd_bot.py`, проверяет его и перезапускается (фарм продолжается).
При обновлении со старой версии раздел Wastelands догружает недостающие компоненты своего выпуска при первом открытии.
Прошлая версия остаётся рядом как `twd_bot_prev.py`. Отключить можно в настройках («Обновляться автоматически»).

## Что не хранится в репозитории

`settings.json` (токен Discord-бота, ссылка приватного сервера), журнал и снимки из папки `debug` —
они остаются только на твоём компьютере.
